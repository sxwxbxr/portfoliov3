Derivative 0.2.0 is on npm. `@sweberdev/derivative` and `@sweberdev/derivative-react` gain three features, and Derivative Pro gains two.

## GitHub Releases as a source

Not every project keeps a CHANGELOG.md. If you write your notes on GitHub, Derivative can now read them directly:

```sh
npx derivative build --source github --repo acme/app
```

Drafts are skipped, pre-releases too unless you pass `--prereleases`. Notes generated by GitHub are cleaned up: the "New Contributors" list and the "Full Changelog" line go, "by @user in …" becomes a link, and prefixes like `feat:` or `fix:` set the entry type. A release name that says more than the tag becomes the release title. Public repositories need no token; for private ones, set `GITHUB_TOKEN`.

## Announcement toast

A badge is easy to miss when a release really matters. With the new `announce` attribute, the widget shows a small toast next to the button for the newest unread release that has a title:

```html
<derivative-widget src="/changelog.json" announce></derivative-widget>
```

Each release is announced once per reader. "Show" opens the panel, "Dismiss" keeps the unread badge. Patch releases without a title never interrupt anyone. The toast is a status region, so screen readers announce it without moving focus, and a `derivative-announce` event tells your analytics when it appeared.

## Type filter

Internal refactors and deprecations are useful in a developer changelog but noise for most app users. `types` limits the panel to the entry types you choose:

```html
<derivative-widget src="/changelog.json" types="feature,fix"></derivative-widget>
```

In React, both are props: `<WhatsNew src="/changelog.json" announce types={["feature", "fix"]} />`.

## Derivative Pro 0.2.0

- **Mastodon:** `derivative-announce post --to mastodon` posts each release as a status of at most 500 characters, with the changelog link and your hashtags. The token stays in an environment variable and only needs the `write:statuses` scope.
- **CSV export:** `derivative-insights report --csv releases.csv` writes readers, opens and clicks per release, plus opens per day, ready for Excel. Values that look like spreadsheet formulas are defused.

Existing licences get the update automatically. Pro starts at 12 CHF per month.
